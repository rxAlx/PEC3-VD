# Web storytelling para PEC 3

Estructura minima para montar la narracion con Scrollama.

## Archivos

- `index.html`: pagina principal de la historia.
- `styles.css`: maquetacion y estetica.
- `script.js`: logica de cambio de escena.

## Grafico usado

La pagina espera estos PNG en `../graficos/`:

- `origen_turistas.png`
- `precio_reservas_por_mes_vs_cancelaciones.png`
- `reservas_totales_vs_canceladas.png`
- `tipo_viaje_por_mes.png`

## Como probarlo

Abre `index.html` en el navegador o sirve la carpeta con un servidor local.

Ejemplo:

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000/javascript/`.
